# Task Assign System

A web-based task management system that helps managers or faculty assign tasks to workers or students, track progress, and manage everything through secure, role-based access. Built to make task delegation and follow-up simple, organized, and transparent for both sides.

🔗 **GitHub Repo:** [Task Assign System](https://github.com/Rameshwarsonawane/TaskAssignSystem)
🎥 **Demo Video:** [Watch here](https://youtu.be/5Nuk8Y8e0FA?si=K0cL3oZFDXcnqx_F)

---

## 📌 About the Project

Task Assign System is designed to solve a simple but common problem — keeping track of who's doing what. Whether it's a manager assigning work to a team or a faculty member assigning tasks to students, this app provides a clean interface to create tasks, assign them, and monitor progress until completion.

It was built as a full-stack project to strengthen my understanding of frontend design, backend logic, database management, and secure authentication — all working together in a real, usable application.

---

## ✨ Features

- **Task Assignment** – Managers/faculty can create and assign tasks to specific workers/students.
- **Progress Tracking** – Real-time status updates so everyone knows where a task stands (pending, in-progress, completed).
- **Notifications** – Users are notified when a new task is assigned or when a status changes.
- **Role-Based Access Control** – Separate permissions and views for managers/faculty vs. workers/students.
- **Secure Authentication** – Login system to ensure only authorized users can access the platform.
- **Responsive UI** – Clean, attractive interface that works smoothly across screen sizes.

## ⚙️ How It Works

1. Users log in based on their role (manager/faculty or worker/student).
2. Managers/faculty can create new tasks and assign them to specific users.
3. Assigned users receive a notification and can view their tasks on their dashboard.
4. As work progresses, users update the task status.
5. Managers/faculty can track progress across all assigned tasks in real time.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/Rameshwarsonawane/TaskAssignSystem.git
   ```
2. Set up a local server environment (e.g., XAMPP/WAMP) with PHP and MySQL.
3. Import the provided SQL file into your MySQL database.
4. Update the database connection settings in the config file with your local credentials.
5. Place the project folder inside your server's root directory (e.g., `htdocs` for XAMPP).
6. Run the project through `localhost` in your browser.
